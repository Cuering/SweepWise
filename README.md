# SweepWise 残件管家

一个免安装的绿色软件：帮你清理**已卸载软件的残留目录**、**各种缓存**与 **AI Agent 工作区**，清理前全部先进隔离区、可一键恢复，每步写入审计日志。

> ⚠️ **测试版声明**
> 本软件目前为**测试版本**，仅建议在你有把握的目录上试用。
> 作者**不负责任何数据丢失或程序损坏**，使用后果自负。
> 清理前请先通过「隔离区」确认条目，重要文件请自行备份。

## 使用方式（绿色版）

1. 去 [Releases](https://github.com/Cuering/SweepWise/releases) 下载最新版 `SweepWise.exe`（单文件，无需安装，无需 Node/Bun 环境）。
2. 双击运行，浏览器会自动打开 `http://127.0.0.1:7310`（端口被占用时自动顺延）。
3. 在界面里选择模块扫描 → 勾选条目 → 点「清理所选」→ 本体移入隔离区。
4. 确认无用后，再到「隔离区」点「彻底删除」真正释放磁盘；反悔可随时「恢复」。

**更新**：顶栏「检查更新」按钮会从 GitHub 拉取最新版；发现新版本时点「升级」即可自动下载、校验（SHA256）、替换并重启。也可以在命令行里跑 `SweepWise.exe` 查看日志。

> 想用源码开发模式？本机装好 Node 后执行 `npm start`，默认同样跑在 7310。

## 功能

| 模块 | 说明 |
|---|---|
| 总览 | 三大模块汇总统计 + 一键清理所有「可清理」项 |
| 卸载残留 | 对账注册表 Uninstall 项与 AppData 目录，识别孤儿残留 |
| 缓存清理 | 常用软件缓存 + 动态探索已安装软件的 Cache/Logs 子目录 |
| Agent 工作区 | opencode / Claude / Codex / Cursor 等 AI 工具目录 |
| 隔离区 | 所有清理的本体都在这里，支持恢复 / 彻底删除 |
| 审计日志 | 每次操作的 JSONL 记录，可导出 |

### 安全分级

每个发现项带三档标签：

- **可清理**：能明确判定为缓存/残留，可放心隔离
- **先询问**：存在不确定因素，默认不勾选，需你人工确认
- **禁动**：系统路径 / 运行中进程 / 硬黑名单，界面标红且不可勾选

系统路径有硬黑名单双重拦截，隔离区采用「先移后删」，跨盘自动复制兜底。

## 数据存放

所有运行数据（隔离区、清单、审计日志、配置）保存在用户目录 `~/.sweepwise/`：

```
~/.sweepwise/
├── quarantine/       # 被隔离的文件（可恢复）
├── manifest.json     # 隔离清单
├── audit.jsonl       # 审计日志（逐行 JSON）
└── config.json       # 忽略列表等配置
```

删除软件本体不影响这些数据；再次运行同一 exe 会继续使用。

## 构建

本仓库采用**模块化设计**，源码结构：

```
server.js         # HTTP 入口：静态 UI + API + 端口自动顺延
src/
  engine.js       # 扫描引擎（残留/缓存/Agent + 安全分级）
  trash.js        # 隔离区 / 恢复 / 彻底删除 / 审计 / 忽略
  updater.js      # GitHub 更新：检查 / 下载 / SHA256 校验 / 自替换
  version.js      # 版本号与仓库地址
  ui-files.js     # 构建时生成的内嵌 UI（勿手改）
ui/               # 前端（index.html / style.css / app.js）
build.mjs         # 构建脚本：内嵌 UI + 打包单文件 exe
```

打包单文件绿色 exe（需要本机装有 Bun）：

```bash
node build.mjs        # 产物：dist/SweepWise.exe（约 94MB，含运行时，免安装）
```
